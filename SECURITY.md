# Security Policy

## Supported versions

Only the default branch and the latest release line receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory flow for this repository, or contact the project maintainers privately with reproduction steps, impact, and a safe remediation suggestion.

Include only the minimum sensitive information necessary. Do not include credentials, private keys, or user data in an issue, pull request, commit, or log.

## Automated checks

Pull requests run dependency audit, CodeQL, Dependency Review, static analysis, and build validation. Findings that fail a required check must be fixed before merge.
