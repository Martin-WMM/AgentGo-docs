# 解决的问题

AgentGo 关注的不是让模型“看起来更聪明”，而是让智能体系统变得可理解、可控制、可演进。

## 从一次性调用到持续运行

简单的模型调用适合单轮问答，但真实应用通常需要多轮观察、决策、执行和反馈。AgentGo 将这些步骤组织成清晰的 Agent Loop，让智能体能够在任务上下文中持续工作。

## 从隐式行为到可观测行为

当工具调用、上下文拼接和状态变化全部隐藏在业务代码里，问题很难复现。AgentGo 鼓励把每个动作、输入、输出和中间状态显式化，从而支持日志记录、调试和评估。

## 从临时脚本到可演进系统

智能体项目往往从一个 Prompt 开始，最终却需要权限控制、工具编排、失败恢复和质量评估。AgentGo 通过明确的运行时边界，让这些能力可以逐步加入，而不必推翻原有实现。

## 从模型中心到系统中心

模型只是智能体系统的一部分。AgentGo 将模型、工具、状态、策略和运行环境放在同一个工程视角下设计，帮助团队构建稳定、可维护的智能体产品。
