# 数据设计

本目录将基于已发布的后端契约说明领域数据、存储边界、数据生命周期与审计要求。

系统事件保存在 `tbl_system_event`。每条记录包含事件名称、domain、操作人、备注和发生时间，并带有创建人与更新时间等审计字段。保留策略只存储最近三个月内最新的 1000 条，超出部分由写入和每小时清理任务删除。接口说明见 [系统事件](../06-API设计/system-events_zh.md)。
